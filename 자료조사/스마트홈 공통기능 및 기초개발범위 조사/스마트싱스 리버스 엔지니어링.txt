장소

장소 관리 화면
 - 장소 리스트(실시간 업데이트) -> 선택시 장소 설정 화면으로 이동
 - QR 코드 스캔 -> 커스텀된 QR 사진 인식 기능
 - 새 장소 추가 버튼 -> 

장소 QR 코드 공유 화면
 - (안드로이드)wifi 프로필 공유
 - 사용 기능 설정 권한 기능
 - (장소 추가시만 표시됨)완료 버튼 -> 홈화면

장소 설정 화면
장소
 - 이름
 - 위치
 - 장소와 시간대(기본)
 - 장소 상태
 - 방 갯수(방 n개)
 - 배경화면 선택 및 표시 기능 삽입
멤버
 - 멤버 수
 - 멤버 초대

멤버 리스트 화면
 - 멤버이름/이메일이 1개 묶음으로 리스트
 - 이전 버튼

멤버초대
 - QR 코드 사용 버튼 -> 장소 QR 코드 공유 화면 이동
 - 초대장 보내기 버튼 -> 초대장 보내기 화면으로 이동
 - 링크 공유 버튼 -> 링크 공유 화면으로 이동

동의화면
 - 동의할 약관 + 동의합니다. 표시
 - 취소 버튼 -> 이전화면
 - 허용 -> (이동하려던 다음 타겟으로) 화면 이동

링크 공유 화면
 - 이전버튼
 - 초대 UI 미리보기
 - 사용기능 설정 -> 사용기능 설정화면 이동
 - 보내기 버튼 -> 공유 UI 호출
 - 새 링크 만들기 버튼 -> 새 링크 만들기 유의사항 확인

초대장 보내기 화면
 - 계정 주소 입력창
 - 사용기능 설정 버튼 -> 사용기능 설정 화면 ui 삽입

사용기능 설정 화면
 - 모든기능 라디오 버튼
 - 기기제어만 라디오 버튼
	- 특정기기만 사용(기기가 없는 경우 비활성화) -> 있으면 기기 리스트 1개 이상 선택가능
	- 만료일 토글스위치 -> 활성화시 기기 기본 날짜 선택 UI 호출 및 반영 
 - 클립재생 권한 토클스위치

방
방 관리
 - 방 리스트
 - + 버튼 -> 방 이름 선택(직접설정시 직접 입력 가능)
 - ... 버튼 -> 편집 -> 편집모드 변화 및 삭제 가능(- 버튼 누르면 삭제 선택지 이동)

방 추가
 - 방설정 UI 재활용
 - 저장 버튼(값 반영후 방관리로 이동)
 - 이전 버튼

방 설정
 - 방 이름
 - 배경화면 선택 및 표시 기능 삽입
 - 방 삭제 -> {이름} 를 삭제할까요 선택지 표시(취소시 이전화면, 삭제시 반영후 방 리스트 화면 이동)


배경화면 선택 및 표시 기능
 - 배경화면 -> 선택시 카메라 / 사진 / 기본 배경화면 / 취소버튼 표시
 - 배경화면 미리보기


방 삭제 선택지
 - "(방 이름)을 삭제하시겠습니까"표시
 - 취소버튼 -> 이전화면
 - 삭제버튼 -> 삭제후 (방 관리)으로 이동

장소 추가 화면
 - 이름(텍스트)
 - 위치 화면 이동 버튼(입력후 저장시 주소 반영)
 - 시간대 입력 기능(기본적으로 휴대전화 위치 시간대, ? 버튼 클릭시 자세한 설명 나옴)
 - 취소 -> 이전화면 / 추가 -> 이름 중복체크 -> 기기 추가 화면

위치 화면 
 - 지도 화면 : 기본 지도 API 이용
 - 위치 반경 : 조정시 화면 자동 확대 및 축소(250m 기준으로 이보다 커지면 지도 확대/축소) 
	- 선택(현재) 위치 표시
	- 현재 위치 측정 후 주소 업데이트(지도도 반영)
 - (안드로이드는 이전)취소/저장 버튼

설정

문의하기
 - 자주하는 질문 -> 인터넷 호출
 - 1:1 질문 -> 질문내용 화면 호출
 - 오류보내기
 - 내 문의 이력

질문 내용 화면
 - 선택지(일반문의/제안)

방 선택 및 기기 선택 화면
 - 방 선택 리스트
 - 기기 선택 리스트
 - 기기 종류별 선택

기기 종류별 선택화면
 - 기본 기기 리스트업(중복선택 가능하도록 세팅)
 - 계속(기기 n개) 버튼(비선택시 비활성화 표시)

1:1 질문하기 화면
 - 유형(고정)
 - 관련기기(고정)
 - 문제가 마지막으로 발생한 날짜 및 시간(텍스트 입력)
 - 상세정보(텍스트 입력)
 - 파일첨부 -> 사진촬영(사진촬영 UI 호출) / 사진 보관함(사진 선택 UI 호출) / 취소(이전화면)
 - 이전 -> 의견을 보내지 않고 삭제 여부 확인 -> 삭제후 문의하기 메뉴로 이동
