각 앱 별 사용 후기

유의사항
 - 본인의 경우는 앱 디자인, 접근성, 실용성 기준으로 평가 
 - 평점의 경우에는 같은 기준 + 실사용 기준으로 평가
 - 각 평점은 본인의 디바이스(아이폰/갤럭시) 기준으로 평가

스마트홈 기본기능 기준
 - 장소 관리 -20점
 - 방 관리 - 20점
 - 기기 관리 - 20점
 - 기타 편의성 - 20점
 - 오프라인 조작 - 20점

앱 기능성 및 디자인 평가 기준
 - 사용자 편의성 - 40점
 - 디자인 트렌드 - 20점
 - 번역 상태 및 내용 정확도 - 40점

스마트싱스*
버전 : 아이폰 1.7.52.32, 갤럭시 1.8.52.23

스마트홈 기본기능 기준
 - 장소 관리 - 20점
 - 방 관리 - 20점
 - 기기 관리 - ?점
 - 연결 편의성 - 8점(다양한 연결방식 X)
 - 기타 편의성 - 10점
 - 오프라인 조작 - 10점

앱 기능성 및 디자인 평가 기준
 - 사용자 편의성 - 34점(일부 매뉴가 정렬이 되지 않아 난잡하다 느낌)
 - 디자인 트렌드 - 20점
 - 번역 상태 및 내용 정확도 - 40점

앱 사용하면서 느낀점
 - 로그인을 하지 않아도 사용이 가능함, 
 - 디자인 패턴이 살짝 다르지만 전체적인 기조는 같음. 
 - lg thinq 등의 제휴사 앱에서의 옮기기 기능 지원
 - 갤럭시 디자인 패턴이 적용되어 있는 모습(예시 : 로드 애니메이션 등)
 - 기기 추가시 로그인해야함.
 - 실시간으로 업데이트하는 방식이 적용되어 있어 타 기기에서 변경하면 곧바로 변경된다.
 - 기기 추가시 연동도 편하게 되어있음.

플랫폼간 차이점
 - 애플 : 애플의 리퀴드 글래스 디자인 기준을 따라가고 있음. 갤럭시 대비 기능은 축소됨(실험실 기능 등), 블루투스 통합관리 안됨, 홈화면에 정보제공 주체가 표시되어 있음
 - 갤럭시 : 갤럭시 플랫폼의 디자인 기준을 따라가고 있음. 기기추가시 로그인하지 않아도 됨 다만 부가기능 이용시 로그인 필수

장단점
 - 장점 : 앱이 사용자 친화적이며, 사용하기 편하게 되어있다. 전반적으로 편의성이 크고 관련기능이 들어가있다.
 - 단점 : 기본적으로 정보가 너무 많이 표시되어 있다. 라이프 화면에서 난잡하다. 타 기기 추가시 기기 연결이 많이 복잡하다. 오프라인 사용시 제약이 많다.


lg thinq*

스마트홈 기본기능 기준
 - 장소 관리 -20점
 - 방 관리 - 20점
 - 기기 관리 - ?점

 - 디자인 트렌드 - 14점(몇년전 디자인 but 나쁘지 않음)
 - 번역 상태 및 내용 정확도 - 40점

앱을 사용하면서 느낀점
 - 디자인 드렌드가 뒤쳐져 있는 느낌이 강함(이는 단점이 아님), 블러가 많이 들어간 느낌, LG의 독자적 디자인 언어가 많이 들어감. 
 - thinq play라는 자체 스토어가 있어 거기서 허브에 기능을 설치 할 수 있음. 삼성과 같이 활용하는 방법 등이 있음(앱가이드 포함)
 - 리포트라는 기능으로 IoT 기기의 현황을 요약해서 표시함. 
 - 제품(등록 기기)의 사용설명서를 표시하는 기능이 있음. 구독 가전을 관리할 수 있음
 - 생활 서비스라는 이름으로 제휴사를 홍보하는 서비스도 있음. 
 - 삼성과 달리 자사 제품을 홍보 및 구매하도록 유도한 느낌이 듬
 - 설정에 광고가 조그많게 들어가 있음.

플랫폼간 차이점
 - 애플 : 삼성과 달리 애플의 디자인 언어가 들어가지 않음.
 - 갤럭시 : 

장단점
 - 장점 : 삼성과 다르게 대한민국에 좀더 특화된 서비스를 하는 느낌을 받았으며, 나머진 삼성과 같다.
 - 단점 : 해외에서 사용할때, 제약이 많은 기능이 있다 느꼈으며, UI/UX에서 오는 딜레이 등이 합쳐져 앱 자체에서 느린 느낌이다. 하나하나 봤을땐 광고가 많다 느낌.

 - 단점 : 특정 상황에서 오류가 발생함. 가이드가 거의 없어서 편의성에선 아쉬움, 방이 없음, 느림

기가지니 and 기가지니 홈 IoT

사용하면서 느낀 점
 - 기가지니 가입자만 접근 가능한게 많음
 - 기본 로그인은 필수
 - 기가지니 가입자만 가능함
 - web 기반 IoT
 - IoT 기기를 연동하려면 기가지니가 지원하는 주택의 IoT 연결작업이 필요
 - 그외 제휴사를 이용한 로그인 및 연동 작업이 필요함
 - 모든 조건이 충족된다면 접근성은 괜찮음.
 - 다만 폐쇄성이 모든것을 좌우함
 - 블루투스식으로 연결이 가능함
 - 기가지니 연동시 본인인증 준필수
 - 장소는 한곳만 가능

플랫폼간 차이 : 없음

 - 장점 : 기가지니에 가입된 기기의 IoT 기기를 조종이 가능함
 - 단점 : 다른 스마트홈 앱과 매우 대조되는 폐쇄성, 연결과정에 필요한 온라인 연동작업, 인터넷 연결 없인 아무것도 못함

 - U+ 가입시 IoT 기기를 위한 스마트홈 앱임 그러므로 기기 연동시 스마트홈 가입번호 및 가입자 요구
 - 폐쇄성 높음
 - 반 자동화 가능
 - 장소는 한곳만 가능

플랫폼간 차이점 : 없음

장단점
 - 장점 : U+스마트홈에 가입된 기기의 IoT 기기를 조종이 가능함, web기반이라 통합 제어 가능
 - 단점 : 다른 스마트홈 앱과 매우 대조되는 폐쇄성, 연결과정에 필요한 온라인 연동작업, 인터넷 연결 없인 아무것도 못함


누구 스마트홈

사용하면서 느낀점
 - web 기반 IoT
 - 로그인 및 휴대폰 인증 필수
 - 타 스마트홈과 마찬가지로 계정 연동식 IoT 기기 제어
 - 호환성 낮음
 - 인터페이스 자체는 현대적
 - 마찬가지로 주택 IoT 연동 가능

플랫폼간 차이점
 - 애플 : 
 - 갤럭시 :

장단점
 - 장점 : 인터페이스가 현대적이다. web 기반이라 통합제어가 가능하다. 현지 사정에 맞춰서 기기 연동이 가능하다.
 - 단점 : 폐쇄성이 짙다. 인터넷 연결 없인 아무것도 못함


홈 어시스턴트

사용하면서 느낀점
 - 오픈소스라 직접 다 설정해야함
 - 사용자가 HA OS를 구축하고 이에 대응할 준비를 다 마쳐야 됨.
 - 일단 세팅만 되면 앱이 자동으로 업데이트하고, 자동으로 구성해줌
 - 다만 서버에서 이름, 주소, 비밀번호, 설정을 본인이 해야함
 - 장소같은건 없음. 하나의 허브라고 생각되는지, 장소는 없고, 방만 있음
 - 타 HA OS와 연동이 가능함
 - 개요도 편집이 가능함
 - 전력 대응해서 IoT 기기를 세팅할 수 있음.
 - 그외 가스, 수도, 태양광, 가정용 배터리 등의 IoT 센서도 연동이 가능함
 - 이를 통해 커스텀된 통계를 만들수 있음
 - 로그북을 통해 디테일한 정보를 알 수 있음.
 - 센서의 업데이트나 나의 상태 등을 알 수 있음.
 - 히스토리를 통해 시계열로 세팅 가능
 - 할일 목록을 통해 자동화도 가능함
 - 기본적으로 호스트를 기반해서 추적, 이로인해 허브에 네트워크적으로 연결되어 있어야 조작 가능
 - 주요 프로토콜은 다 지원함.

플랫폼간 차이점
 - 애플 : 
 - 갤럭시 :

장단점
 - 장점 : 그 어느 플랫폼보다 넓은 호환성, 세팅 정도에 따라 상상하는 모든 것을 연결시킬 수 있음(오픈소스라 커스텀이 가능)
 - 단점 : 세팅난이도 높음, 개발자 최적화 환경(사용자에게 다소 불편할 수 있음)
