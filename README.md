# 브랜치

## 브랜치 참고사항
 - 이 프로젝트는 구버전과 신버전으로 나뉘어져 있으며, 기본적으로 신 파일과 구 파일을 분리하여 개발한다.
 - 26년 10월 이전까지를 구버전으로 칭하고, 이후부턴 신버전으로 정의한다.
 - 구 브랜치/파일 의 경우 웬만해선 그대로 두며, 기존과 같이 운용하는 경우엔 구버전 폴더를 만들어 보관하여 개발에 방해가 되지 않도록 한다.


## 브랜치 설명
 - main : 프로젝트의 메인 브랜치이며, 자료조사/기획/설계에 필요한 자료 모음집
 - develop(본인이름) : (구 브랜치)본인이름으로 되어있는 개발폴더(개발 후 나중에 alpha 브랜치에 하나로 병합)
 - alpha : 통합테스트가 끝난 직후의 프로토타입 버전(불안정)
 - beta : 알파버전 기반으로 안정화되어 좀더 심층적인 테스트가 필요한 버전.(안정)
 - release : 베타버전의 심층 테스트를 거친 버전(안정).
 - culiso(main과 통합예정) : 각종 개발 다이어그램이나 설계 등의 파일 저장소.
